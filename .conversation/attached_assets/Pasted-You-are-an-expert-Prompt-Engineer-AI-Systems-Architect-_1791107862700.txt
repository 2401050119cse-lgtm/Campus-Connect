# 6. Important Reliability Feature

This is particularly important because **reliability is the core problem you're solving**.

Don't allow everyone to publish information directly.

Use an approval workflow:

```text
Faculty/Coordinator
        ↓
Create Announcement
        ↓
Admin Review
        ↓
Approve
        ↓
Published
        ↓
Students Notified
```

Each announcement should also have:

* Published date
* Last updated date
* Organizer
* Verification status

For example:

> ✅ **Verified College Announcement**

This makes the platform more trustworthy than random WhatsApp messages.
